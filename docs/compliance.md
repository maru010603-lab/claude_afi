# コンプライアンス方針・差分一覧・公開ゲート

## A. 参考資料からの差分一覧(これ以外に手を加えない)
| # | 差分 | 理由 |
|---|---|---|
| D1 | 「体験談」は方針責任者の**実体験メモ**にある事実のみで作る。無い部分は空欄にする(架空の体験は書かない) | 架空体験談は優良誤認・ステマに該当し得る。参考資料自身も「実体験を挿入する余白」を設計している |
| D2 | X投稿・記事・LINE1通目に「PR/広告を含む」旨を必ず明記 | ステマ規制(景品表示法、2023年10月〜)。A8もPR表記を必須としている |
| D3 | 3通目「失敗体験」・6通目「成約者事例」は実在事実のみ。無ければ一般論に置換 | 同上(架空事例の排除) |
| D4 | 案件リサーチの単価・承認率は根拠のある値のみ。不明は「要確認」 | AIは管理画面を見られず、数値を創作しかねないため |
| D5 | 保険・不動産投資は当面「保留カテゴリ」(下記B参照) | A8の保険業法上の制限など |
| D6 | LINE導線は公開ゲート(下記C)を通過するまで公開しない | ASP規約(クローズド配信の制限)の確認が未了 |
| D7 | 収益実績・成約率を当社コンテンツに掲載しない | 検証不能な実績表示は優良誤認 |

## B. カテゴリ別の扱い(推奨案)
| カテゴリ | 扱い | 根拠・条件 |
|---|---|---|
| 転職 | 第1弾から着手 | 登録型。個別キャリア相談はせず一般情報のみ |
| 金融(口座開設) | 第1弾から着手 | 金商法: 利益の確実性を暗示する表現・損失負担表示・古い情報は禁止(A8)。個別の投資助言は行わない |
| 保険 | 保留 | A8: 一般メディア会員は保険商品の詳細紹介不可(配布素材・社名のみ)。案件ごとの方針確認が必須 |
| 不動産投資セミナー | 保留 | 勧誘規制が厳しく、案件ごとの広告主条件を要確認 |

## C. 公開ゲート(LINE導線・記事を実際に公開する前の必須条件)
- G1: 各案件の広告主条件で、SNS/LINE/メルマガ配信が許可されているか確認(方針責任者がASP管理画面で確認)
  - A8のSNSガイドラインは「外部非公開又は閲覧制限のある環境での利用は禁止」「A8未登録の個人宛メール/SNSメッセージでの広告配信は禁止」と定める。LINEステップ配信(友だち限定の個別配信)はこれに抵触し得るため、案件・ASPごとの許可が確認できるまで案件LPを含む配信は行わない
- G2: 利用するX・LINE等をASPにメディア登録(A8はSNS利用時のサイト登録が必須)し、PR表記・広告掲載URLの提出ルールに従う
- G3: X/LINEのプロフィールにPR(広告を含む)旨を明示
- G4: 記事・LINE用の実体験メモを方針責任者が提供
- G5: 保留カテゴリは案件ごとの可否確認後に解禁

## D. 恒常ルール
- 断定表現(絶対/必ず/確実)禁止、命令形不使用
- ランキング・比較は客観的根拠・正確な情報・公正な比較(A8基準)
- 薬機法・健康増進法の効能表現は扱わない(美容・健康系は対象外)
- 個別の金融・投資助言は行わない(一般情報の提供のみ)
- 実リンクの生成・貼付、アカウント作成、パスワード/APIキーの取り扱い、投稿の最終公開は統括が行わない
