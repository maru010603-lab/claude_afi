# コンプライアンス方針・差分一覧・公開ゲート

## A. 参考資料からの差分一覧(これ以外に手を加えない)
| # | 差分 | 理由 |
|---|---|---|
| D1 | 「体験談」は方針責任者の**実体験メモ**にある事実のみで作る。無い部分は空欄にする(架空の体験は書かない) | 架空体験談は優良誤認・ステマに該当し得る。参考資料自身も「実体験を挿入する余白」を設計している |
| D2 | X/Threads/Instagram投稿・記事に「PR/広告を含む」旨を必ず明記 | ステマ規制(景品表示法、2023年10月〜)。A8もPR表記を必須としている |
| D3 | ~~LINE3通目・6通目の実在事実のみ~~ → LINE除外のため保留(LINE導入時に適用) | — |
| D4 | 案件リサーチの単価・承認率は根拠のある値のみ。不明は「要確認」 | AIは管理画面を見られず、数値を創作しかねないため |
| D5 | 保険・不動産投資・金融口座開設は当面「保留カテゴリ」(下記B) | A8の保険業法上の制限、公開情報上に購入・取引不要の高単価案件が見当たらないため |
| D6 | **LINE(ステップ配信)は採用しない**。導線は「SNS→プロフ→固定→体験談記事→案件LP」 | LINEはA8の掲載可能SNSに含まれず、非公開・閲覧制限のある環境での利用は禁止 |
| D7 | 収益実績・成約率を当社コンテンツに掲載しない | 検証不能な実績表示は優良誤認 |
| D8 | 記事の「LINE公式への導線」を「案件への導線」に置換。X投稿の誘導先は記事 | D6に伴う変更 |
| D9 | 案件選定に追加基準(提携可否、SNS掲載条件・否認条件、成果確定条件、単価の安定性) | 承認率だけでは実収益を判断できないため(推奨案) |

## B. カテゴリ別の扱い(推奨案)
| カテゴリ | 扱い | 根拠・条件 |
|---|---|---|
| 転職 | 第1弾 | 無料面談型が複数あり基準に合致。個別のキャリア相談はせず一般情報のみ。職種は1つに絞る想定(確認結果を見て選定) |
| 金融(口座開設) | 保留 | 公開ランキング上、購入・取引不要かつ1万円以上の個人向け案件が見当たらない。金商法: 利益の確実性を暗示する表現は禁止 |
| 保険 | 保留 | A8: 一般メディア会員は保険商品の詳細紹介不可(配布素材・社名のみ) |
| 不動産投資セミナー | 保留 | 勧誘規制が厳しく、案件ごとの広告主条件を要確認 |

## C. 公開ゲート(実際に公開する前の必須条件)
- G1: 各案件のプロモーション詳細で「SNS掲載」条件と否認条件を確認(方針責任者)。記載が無い場合(公式ヘルプに記載なしの扱いは明記されていない)は、否認条件にA8ルール遵守の注釈のみで個別の禁止が無いことを確認した上で、A8規約の範囲(登録メディア・PR表記・所定のリンク)で扱う。不安な案件は広告主へ確認する。案件に「LINE経由の申込は否認」等の個別条件がある場合はそれに従う
- G2: 使用するX・Threads・Instagram・記事媒体(note等)をA8・もしもにメディア登録し、リンクは「SNS・note用」など所定の方法で取得。PR表記・広告掲載URLの提出ルールに従う
- G3: プロフィールと各投稿・記事にPR(広告を含む)旨を明示
- G4: 記事用の実体験メモを方針責任者が提供
- G5: 保留カテゴリは案件ごとの可否確認後に解禁
- G6: LINE導入を再検討する場合は、A8・案件ごとの許可(書面等)を先に取得してから設計する

## D. 恒常ルール
- 断定表現(絶対/必ず/確実)禁止、命令形不使用
- ランキング・比較は客観的根拠・正確な情報・公正な比較(A8基準)
- 薬機法・健康増進法の効能表現は扱わない(美容・健康系は対象外)
- 個別の金融・投資助言は行わない(一般情報の提供のみ)
- 全案件の注意書き「一般消費者が閲覧できる位置にわかりやすく表示」に従い、記事・投稿の目に付く位置に、広告(PR)であることと、成果条件・対象条件(年齢・地域・面談実施など)の要点を表示する(該当箇所の正確な指示内容は方針責任者に要確認)
- 自分の体験のために自分のアフィリエイトリンクから申し込まない(自己申込による成果は不正扱いのおそれ。体験時は通常の公式ページから申し込む)
- 実リンクの生成・貼付、アカウント作成、パスワード/APIキーの取り扱い、投稿・記事の最終公開は統括が行わない
