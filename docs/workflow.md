# 制作〜投稿フロー

方針: 「予約投稿ツールを間に挟む」運用。

## フロー
1. **企画・下書き**(統括が自律実行): ニッチ戦略に沿ってネタ出し→下書きを `content/<platform>/YYYY-MM-DD_タイトル.md` に作成。アフィリエイトリンクはプレースホルダー `{{AFF_LINK:案件名}}` で記載し、実リンクへの置換は方針責任者側で実施(実際のASP案件IDを扱うため)。
2. **コンプライアンスチェック**(統括が自律実行): 景品表示法(優良誤認・有利誤認)、各SNSの広告表示ルール(#PR 表記など)、ASPの規約に照らしてチェック。NGがあれば下書きを修正。
3. **人手レビュー(あなた)**: `content/` 配下の下書きを確認し、アフィリエイトリンクを実リンクに差し替え。
4. **予約投稿ツールへの登録(あなた or 連携済みツール)**: Buffer/Later等の予約投稿ツールに下書きを投入。ツール選定・API/アカウント連携はあなたが実施。連携が完了すれば、投入作業自体の自動化(API経由でのドラフト登録)は統括側で対応可能。
5. **公開**: 予約投稿ツールのスケジュールに従って自動公開。ツール側の設定を変えない限り、都度の個別承認は不要。

## 現状のツール未接続時の代替
予約投稿ツールが未接続の間は、統括は下書きの作成・蓄積のみを行い、`decisions.md` に「投稿待ちキューが◯件たまっています」と記載して知らせる。

## 予約投稿ツール: Buffer(無料プラン)採用

2026-09-17、Bufferの無料プランを使うことに決定。

### Buffer無料プランの制約
- 接続できるSNSチャンネルは**3つまで**
- 1チャンネルあたり**キューに入れられる予約投稿は10件まで**(公開されると枠が空くので月間投稿数の上限ではない)
- チャンネル接続は生涯8回までという制限もあるため、接続後の付け外しは避ける
- Buffer APIは無料プランでも利用可能だが、**個人APIキー方式(ベータ)**。OAuthでの第三者連携は未対応のため、Bufferアカウント所有者(あなた)自身がAPIキーを発行する必要がある

### 統括(私)が代行できない/しない部分
- Bufferアカウント作成、SNSチャンネルの接続(X/Instagram/Threads認証)
- Buffer APIキーの発行申請・生成
- **APIキーの値そのものをこのチャット上でやり取りすること**(トークン類は扱えないポリシーのため)

### 依頼したい手順
1. [buffer.com](https://buffer.com) で無料アカウント作成(未作成の場合)
2. 投稿先チャンネルを接続(上限3つ。おすすめ: X, Instagram, Threads。※InstagramはFacebook連携のビジネス/クリエイターアカウントが必要な場合あり)
3. Buffer APIの個人アクセストークンを申請・発行([support.buffer.com](https://support.buffer.com/en-us/articles/using-buffers-api-GtIYIQilz5) 参照。ベータのため承認待ちが発生する場合あり)
4. 発行できたキーは、**claude.aiのルーティン編集画面(Environment variables/Secrets欄)に直接入力**してください(私には見せないでOKです)。変数名は `BUFFER_API_KEY` を推奨
5. 設定できたら「Buffer連携できた」とだけ教えてください。私はキーの値を見ないまま、ルーティンのタスク内容を更新し、下書きをBufferのキューに自動登録する処理(キュー残数10件を超えないよう管理)を追加します

### 移行後のフロー
1. 統括が下書き作成(変更なし)
2. あなたがリンクをプレースホルダーから実リンクに差し替え(変更なし)
3. ルーティンが `$BUFFER_API_KEY` を使ってBuffer APIにドラフトを送信し、各チャンネルのキューに追加(キューが10件に達している場合はスキップし `decisions.md` に「キュー満杯につき◯件保留」と記録)
4. 公開はBufferのスケジュールに従い自動実行(個別承認不要)
