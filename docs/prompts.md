# プロンプト集

参考資料のプロンプトの再現。【差分】と付した行のみ、法令・規約・LINE除外のため追加・変更している(理由は [compliance.md](compliance.md))。

## プロンプト① 高単価案件リサーチ(木曜)
```text
あなたは国内アフィリエイトの専門リサーチャーです。

以下の条件で「承認率が高くて単価が高い」案件を20個抽出してください。

1. A8/afb/バリューコマース/もしもで扱える案件
2. 1件報酬10,000円以上
3. 承認率70%以上
4. 成果条件が"無料相談"または"無料登録"(購入不要)
5. 会社員・主婦がターゲットに含まれる

各案件について、以下を表形式で:
・案件名
・単価(円)
・承認率
・成果条件
・想定ターゲット(年齢/職業/悩み)
・想定検索キーワード5つ
・記事の切り口3案
・SNS投稿で使える"読者の悩み"3つ

同じジャンルに偏らないよう、
最低4カテゴリー(金融/保険/転職/不動産)に分けて出してください。

【差分】単価・承認率は、ASP管理画面の表示または公開情報で根拠を確認できた値のみ記載し、確認できない項目は推測せず「要確認」と書くこと。
【差分】「LINE配信で使える読者の悩み」は「SNS投稿で使える読者の悩み」に変更。
【差分】各案件の「SNS掲載」条件・否認条件、成果確定の条件も分かる範囲で併記すること(不明は「要確認」)。
```

## プロンプト② 体験談記事(火曜)
```text
あなたは経験10年のアフィライターです。

以下の案件について、体験談ベースの紹介記事を書いてください。

【案件情報】
・案件名:[案件名]
・単価:[金額]
・成果条件:[無料相談/無料登録]
・想定ターゲット:[年齢/職業/悩み]
・【差分】実体験メモ:[方針責任者が実際に申込・相談して得た事実、感想、微妙だった点]

【記事の構成】
1. 冒頭で"読者の悩み"を言語化(500字)
2. 案件が解決策になる理由(700字)
3. 実際に体験した流れ(700字)
4. 微妙だった点(信頼担保のため必ず1つ)(300字)
5. 【差分】案件への導線(無料相談/無料登録への案内。{{AFF_LINK:案件名}})(300字)

【必ず守るルール】
・"絶対"や"必ず"の断定表現は禁止
・薬機法/景表法/金商法のNG表現は排除
・体温のある1人称・敬体
・命令形は使わない
・"AI感"を消すために自分の実体験を挿入できる余白を3ヶ所作る
・【差分】冒頭に「【PR】本記事は広告を含みます」を入れる
・【差分】3・4の内容は実体験メモにある事実のみで書く。メモに無い体験は創作せず【実体験を記入】の空欄にする

【出力】
マークダウン形式で、
最後に"実体験を挿入すべき3ヶ所"に印を付けて
全文を出力してください。
```
(参考資料の「5. LINE公式への導線」は、LINE除外のため「案件への導線」に置換。)

## SNS告知投稿(水曜・参考資料に個別プロンプトなし → 推奨案で補完)
導線「SNS→プロフ→固定→記事」の入口として、プロンプト①の「SNS投稿で使える読者の悩み」をもとに、週30本(X用15+Threads用15)を作成する。
- 1本=読者の悩みの言語化+一般的な情報+記事への誘導(`{{ARTICLE_URL}}`)。案件LPへの直リンクは貼らない
- 文末に必ず「#PR」
- 断定表現・収益実績・架空の体験談は書かない
- フェーズ2(Instagram): リール台本(15〜30秒、テロップ案付き)を週3本、同じルールで作成

## 保留: プロンプト③ LINE7日間ステップ配信(LINE導入時のみ使用)
LINE導入を再検討する場合のために保管。導入前に必ずA8・案件ごとの許可を確認し、[compliance.md](compliance.md) のゲートを再設定する。
```text
あなたはLINE公式のステップ配信設計の専門家です。

以下の案件用に、登録直後から7日間のステップ配信を作ってください。

【案件情報】
・案件名:[案件名]
・想定読者:[属性/悩み]

【7通の構成】
1通目(即配信):登録の御礼+特典配布
2通目(翌日):読者の悩みへの深い共感
3通目(3日目):失敗した過去の体験談
4通目(5日目):解決策の提示
5通目(7日目):案件の詳細紹介
6通目(9日目):成約者の変化事例
7通目(11日目):無料相談への背中押し

【必ず守るルール】
・全て300字以内
・体温のある1人称
・"絶対"などの断定表現は排除
・薬機法/景表法/金商法のNG表現は排除
・7通全てが"同じ人格"で繋がってること
・1〜4通目は案件名を出さない
・【差分】1通目に「このLINEには広告(PR)が含まれます」を明記する
・【差分】3通目・6通目は実在の事実のみ。無い場合は一般論に置き換え、架空の体験談や成約者事例は作らない

【出力】
7通を配信タイミング付きで一気に出力してください。
```
注: 「7日間」と称するが配信は11日目まで(参考資料の記載どおり)。
