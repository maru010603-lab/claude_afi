# 運用方針(参考資料の再現・LINEなし版)

参考資料: 「【月150万達成】Claude × 国内最強アフィ"高単価LINE誘導型"で資産構築」(方針責任者より提供)
本運営は参考資料のモデルから**LINE(ステップ配信)の段階だけを外し**、SNS+公開記事で行う(2026-09-20決定。理由: LINEはA8の掲載可能SNSに含まれず、非公開・閲覧制限のある環境での利用も禁止されているため)。それ以外は参考資料を再現し、オリジナルは加えない。差分は [compliance.md](compliance.md) の差分一覧に限る。
**運用して収益が思わしくない場合は、LINE導入を改めて検討する**(復元用の材料は [prompts.md](prompts.md) の保留欄に保管)。

注意: 本書中の金額・成約率・推移は**参考資料の主張値**であり、検証されておらず、LINE前提の数値である。LINEを外した本運営では、この数値の再現は見込めない。

## 1. モデル概要
Claudeで「高単価案件リサーチ → 体験談記事 → SNSで記事へ誘導 → 案件の無料相談/無料登録の成約」を組み、積み上げる資産型モデル。顔出しなし。
- 変更点: 参考資料の「LINE7日間配信」の役割(育成と成約の後押し)は、公開の体験談記事が担う

## 2. 収益構造(参考資料の主張値・LINE前提)
| 案件カテゴリ | 単価(1件) | 月収 |
|---|---|---|
| 金融口座開設 | 25,000〜35,000円 | 55万円 |
| 保険相談 | 15,000〜25,000円 | 38万円 |
| 転職エージェント登録 | 8,000〜15,000円 | 32万円 |
| 不動産投資セミナー | 20,000〜30,000円 | 25万円 |
| 合計 | | 150万円 |

- 成果条件は「無料相談」「無料登録」のみ(読者は1円も払わない)
- 収入の8割は既存の記事・配信から自動発生、との主張

## 3. 成立理由(参考資料)
1. Claudeで体験談記事の初期構築コストが激減(1本4時間→40分)
2. 無料相談型は成約ハードルが低く承認率が高い(70〜85%)
3. ~~LINE7日間配信で成約率が6倍~~ → LINEなし。代替として、記事で悩みの共感→解決策→体験→懸念点まで完結させる

## 3.5 アカウントテーマ(2026-09-24決定)
- **メインテーマ: 「20代後半〜30代のIT転職」**。第1候補のキャリナビ転職(対象20〜34歳、職種不問)を、IT転職の文脈で紹介するところから開始する
- **拡大候補(運用状況を見て判断。今は着手しない)**: 施工管理・製造系の転職、資格系(転職以外のキャリアアップ)。KPIが一定水準に達した、またはIT系だけでは案件・ネタが不足すると判断した時点で、方針責任者の判断のもとカテゴリを追加する
- 拡大時は、新テーマ用の案件リサーチ(プロンプト①)を追加実施し、[compliance.md](compliance.md) のカテゴリ表(B)に追記してから着手する。既存のIT転職の運用と混在させず、投稿・記事でどちらのテーマか分かるようにする

## 4. 導線(LINEなし版)
SNS(X / Threads / Instagram) → プロフ → 固定投稿 → **体験談記事(公開媒体)** → 案件LP
- 投稿から案件LPへ直リンクは貼らない(参考資料の失敗2の教訓を維持し、必ず記事を挟む)
- 記事の置き場: note(A8のSNS・note用リンクが使える)を推奨(要ASP確認)
- Instagramは投稿本文のリンクが押せないため、プロフィールのリンクから記事へ

## 5. 案件選定基準
参考資料の基準:
- ASP: A8 / afb / バリューコマース / もしも
- 1件報酬 10,000円以上
- 承認率 70%以上(70%未満は扱わない)
- 成果条件が「無料相談」または「無料登録」(購入・取引不要)
- ターゲットに会社員・主婦を含む
- 4カテゴリ(金融 / 保険 / 転職 / 不動産)に分散(本運営では下記の運用制約で転職中心)
- 【推奨案・採用済み】対象外ユーザー条件(年齢・属性等)がある案件は、記事・投稿では対象年齢や申込条件の要点を中立的に書き、詳細確認は必ず公式ページへ誘導する(個別属性の列挙はしない)
- 収益は「成約数 × 単価 × 承認率」。「単価 × 承認率 × 導線」の3層で設計する

追加基準(推奨案・差分D9): 提携申請の可否、案件の「SNS掲載」条件と否認条件、成果確定の条件(面談実施が必要か等)、単価の安定性

運用上のカテゴリ扱い: 転職(第1弾)/ 金融・保険・不動産は保留。詳細は [compliance.md](compliance.md)

## 6. 失敗回避(参考資料の失敗3例)
1. 低単価案件を数で積まない(低単価量産信仰を排除)
2. 導線を軽く見ない(直接LPに送らず、必ず記事を挟む)
3. 承認率を確認せず単価だけで選ばない

## 7. 週次リズムと担当(参考資料の曜日配分を踏襲)
| 曜日 | 作業 | Claude(ルーティン) | 方針責任者 |
|---|---|---|---|
| 月 | 数値確認(記事・投稿のクリック、成約) | KPIファイルの整理・異常検知 | 数値を `reports/kpi.csv` に記入 |
| 火 | 新規体験談記事の生成 | 記事下書き(プロンプト②) | 実体験メモの提供・確認、記事の公開 |
| 水 | SNS告知投稿30本の予約設定 | 30本の下書き作成→Bufferへ | 内容確認・リンク差替 |
| 木 | 新着高単価案件チェック | 案件リサーチ(プロンプト①) | ASP管理画面での承認率・掲載条件の確認 |
| 金 | 週次データ・案件別承認率の確認 | 週次レポート作成 | 数値提供 |
| 土日 | 完全オフ | 実行しない | — |

## 8. ロードマップ(参考資料の推移・LINE前提。本運営の目標ではない)
1ヶ月目 0円(体験談記事5本公開) → 2ヶ月目 12万円 → 3ヶ月目 38万円 → 4ヶ月目 72万円 → 5ヶ月目 105万円 → 6ヶ月目 135万円 → 8月時点 150万円
本運営の見直し点: 運用開始から3ヶ月後の月次レポートで成約が出ない・伸びない場合、LINE導入を検討する(その際は先にA8・各案件での掲載可否を再確認)

## 9. KPI
投稿別・記事別クリック数 / 案件別成約数 / 案件別承認率 / 月次収益(週次で `reports/` に記録)

## 10. 段階導入(推奨案)
- フェーズ1: X + Threads(テキスト投稿)+ note記事。Bufferの無料3チャンネルのうち2つを使用
- フェーズ2: Instagram(投稿・リール)。動画作成ツールの選定・導入後。Claudeはリール台本を作成し、動画化はツール/方針責任者が行う
- 参考資料が提供していない情報: 実際の案件リスト、プロフ・固定投稿文面、詳細ロードマップ(推奨案で補完。詳細は decisions.md)
