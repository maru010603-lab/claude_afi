# 運用方針(参考資料の再現)

参考資料: 「【月150万達成】Claude × 国内最強アフィ"高単価LINE誘導型"で資産構築」(方針責任者より提供)
本書は参考資料のモデルをそのまま再現する。オリジナルの要素は加えない。法令・ASP規約上やむを得ない差分のみ [compliance.md](compliance.md) の「差分一覧」に限定して記載する。

注意: 本書中の金額・成約率・推移は**参考資料の主張値**であり、検証されておらず、本運営の予測値・保証値ではない。

## 1. モデル概要
Claudeで「高単価案件リサーチ → 体験談記事 → LINE7通ステップ配信 → 無料相談/無料登録の成約」の4つの仕組みを1回組み、積み上げる資産型モデル。顔出しなし・撮影なし。

## 2. 収益構造(参考資料の主張値・8月時点)
| 案件カテゴリ | 単価(1件) | 月収 |
|---|---|---|
| 金融口座開設 | 25,000〜35,000円 | 55万円 |
| 保険相談 | 15,000〜25,000円 | 38万円 |
| 転職エージェント登録 | 8,000〜15,000円 | 32万円 |
| 不動産投資セミナー | 20,000〜30,000円 | 25万円 |
| 合計 | | 150万円 |

- 成果条件は「無料相談」「無料登録」のみ(読者は1円も払わない)
- 収入の8割は既存の記事・LINE配信から自動発生(新規記事ゼロでも月120万円以上、との主張)

## 3. 成立理由(参考資料)
1. Claudeで体験談記事の初期構築コストが激減(1本4時間→40分)
2. 無料相談型は成約ハードルが低く承認率が高い(70〜85%)
3. LINE7日間配信で成約率が上がる(直接LP送客比6倍、との主張)

## 4. 導線(6段階)
X → プロフ → 固定ポスト → LINE → 7通ステップ配信 → 案件LP

## 5. 案件選定基準
- ASP: A8 / afb / バリューコマース / もしも
- 1件報酬 10,000円以上
- 承認率 70%以上(70%未満は扱わない)
- 成果条件が「無料相談」または「無料登録」(購入不要)
- ターゲットに会社員・主婦を含む
- 4カテゴリ(金融 / 保険 / 転職 / 不動産)に分散
- 収益は「成約数 × 単価 × 承認率」。「単価 × 承認率 × LINE導線」の3層で設計する

## 6. 失敗回避(参考資料の失敗3例)
1. 低単価案件を数で積まない(低単価量産信仰を排除)
2. LINE公式を後回しにしない(直接LPに送らず必ずLINEを挟む)
3. 承認率を確認せず単価だけで選ばない

## 7. 週次リズム(参考資料)と本運営での担当
| 曜日 | 作業 | Claude(ルーティン) | 方針責任者 |

| 月 | LINE登録数・7日目残存率の確認 | KPIファイルの整理・異常検知 | 数値を `reports/kpi.csv` に記入 |
| 火 | 新規体験談記事の生成 | 記事下書き作成(プロンプト②) | 実体験メモの提供・確認 |

## 8. ロードマップ(参考資料の推移・保証値ではない)
1ヶ月目 0円(体験談記事5本公開) → 2ヶ月目 12万円(高単価4件成約) → 3ヶ月目 38万円(LINE7日間配信完成) → 4ヶ月目 72万円(4案件並列) → 5ヶ月目 105万円(過去記事リライト) → 6ヶ月目 135万円 → 8月時点 150万円

## 9. KPI
LINE登録数 / 7日目残存率 / 案件別成約数 / 案件別承認率 / 月次収益(週次で `reports/` に記録)
