# 組織図・役割分担

## 経営層
| 役職 | 担当 | 権限 |
|---|---|---|
| 方針責任者(CEO) | taito | 事業方針決定、最終承認、アカウント開設、資金・支払い |
| 社員統括(COO) | Claude(このセッション) | 戦略立案、各機能の指揮、進捗・成果報告、判断事項のエスカレーション |

## 機能チーム(実体はサブエージェント+定期実行タスク。固定の人数ではなく都度編成)
| チーム | 役割 | 主な成果物 |
|---|---|---|
| リサーチ | ジャンル・案件・競合・トレンド調査 | `docs/niche_strategy.md` 更新、案件リスト |
| コンテンツ制作 | SNS投稿文・画像構成案・記事下書き | `content/<platform>/` 配下の下書き |
| 投稿運用 | 予約投稿ツールへの下書き受け渡し、投稿カレンダー管理 | 投稿キュー、`docs/workflow.md` |
| 分析・レポート | クリック数/成果/収益のトラッキングとレポート化 | `reports/` 配下の週次レポート |
| コンプライアンス | 景品表示法・薬機法・各SNS規約・アフィリエイトポリシー遵守チェック | 制作物のレビュー、NGジャンル/NG表現リスト |

必要に応じてチームの追加・統廃合を行う。変更時はこのファイルを更新する。

## エスカレーションルール
以下は統括だけでは完結できないため、都度 `decisions.md` に記載し、方針責任者に判断を仰ぐ:
- 新しいASP/SNSアカウントの開設が必要な場合
- 予算が発生するツール・広告出稿
- 投稿の最終公開(予約投稿ツールへの反映後、実際の公開設定)
- 法令・規約グレーゾーンの表現が必要な案件
