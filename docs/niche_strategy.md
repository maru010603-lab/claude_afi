# ジャンル(ニッチ)戦略

## 選定方針
「完全に任せる」との方針を受け、以下の基準で一次選定した:
1. 単価・継続報酬が見込める
2. SNS(X / Instagram / Threads想定)で情報発信しやすく拡散性がある
3. 法規制・炎上リスクが低い(AIが継続的に文章生成する運用と相性が良い)
4. A8.net・もしもアフィリエイト(既存アカウントあり)に案件が豊富

## 主力ニッチ(第一弾)
**「サブスク・通信サービスの乗り換え・比較」**(格安SIM、動画/音楽/学習系サブスク、クラウドツールなど)

理由:
- 月額課金サービスが中心のため継続報酬・高単価案件が多い
- 「節約・お得」情報はX/Instagramで需要が高く、事実ベースの比較記事で構成できるため誇大表現のリスクが低い
- A8.net・もしもアフィリエイト双方に多数の通信・サブスク案件がある

## 第二ニッチ(展開候補)
**「転職・スキルアップ(資格取得・オンライン講座)」**
- 資料請求・無料相談などのリード獲得型で高単価だが、個別のキャリア相談的な発信は避け、あくまで「サービス比較・情報提供」に限定する

## 意図的に避ける/慎重扱いのジャンル
- **美容・健康・ダイエット・脱毛系**: 薬機法・景品表示法上の効果効能表現規制が厳しく、AI生成文章での継続運用は炎上・アカウント停止リスクが高いため当面見送り
- **金融・投資・保険**: 個人への投資助言に該当し得る、規制業種のため当面見送り(比較情報のみで済む案件が明確に切り分けられる場合のみ将来検討)
